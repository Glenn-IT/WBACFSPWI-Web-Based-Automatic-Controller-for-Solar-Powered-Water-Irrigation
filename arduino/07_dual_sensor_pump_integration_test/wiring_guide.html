🌾 Autonomous Rice Field Control Logic (Calibrated 3-Point System)

This integrated test verifies real-world closed-loop irrigation: The pump turns ON when surface standing water drops below 45.0% (Refill threshold) and turns OFF when water reaches 50.0% (Target depth). It includes a 5-second anti-splash minimum runtime to ignore ripples and a 10-second wave settling stabilization window before confirming target attainment.

🌾 Autonomous Verification Sequence

  • 1. Power-Up Stabilization: On boot, Arduino blinks Pin 13 LED for 10 seconds to allow sensor power rails to settle before making irrigation decisions.
  • 2. Refill Test (< 45.0%): Hold HW-080 dry in air. Pump relay clicks ON. Pin 13 LED illuminates.
  • 3. Anti-Splash Test (5s): Submerging probe within 5 seconds will NOT immediately stop pump; the 5000ms minimum runtime guarantees anti-splash ripple immunity.
  • 4. Settling Window Test (10s): Once probe is submerged to ≥ 50.0% after 5s runtime, pump clicks OFF and system enters a 10-second wave settling delay before logging stable state.
