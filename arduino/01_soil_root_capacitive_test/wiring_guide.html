Star Wiring & Power Architecture Reference Table
From (Source) Breadboard Star Node Target Component Wire Color Power / Signal Role
Buck OUT+ (5.0V) Star 5V Red Rail (+) Arduino 5V Pin Red Main System Power: Buck Converter supplies regulated 5.0V to Star 5V Rail, powering the Arduino Uno.
Buck OUT- (GND) Star GND Blue Rail (-) Arduino GND & Sensor GND Black / Slate Star Ground Node: Central zero-volt reference point eliminating ground loops and noise.
Arduino Pin D8 Row 5 (Terminal A) Capacitive Sensor VCC Red / Pink Power Gate: High only during measurement cycle (~100ms) to eliminate DC electrolysis and corrosion.
Arduino Pin A0 Row 15 (Terminal A) Capacitive Sensor AOUT Yellow Analog soil moisture reading (0V to 3.0V) returned to Arduino ADC.

⚡ Star Wiring & USB Data Bridge Architecture

Primary Power: The Buck Converter connected to the 3S Battery provides steady, continuous 5.00V power.
USB Connection: The USB cable is strictly a Serial Data Bridge (115200 baud) for transferring live sensor telemetry to the web dashboard.
