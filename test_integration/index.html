Hardware Pinouts & Wiring Blueprint

Complete reference for all verified modules from tests 01 through 06.

Arduino Uno Pin Assignments
Pin Component Type / Circuit
A0 Capacitive Soil Moisture v1.2 Analog Input (Root Zone)
A1 Surface Water Level Sensor Analog Input (Surface Ponding)
A2 3S 18650 Battery Voltage Divider: 100kΩ (R1) / 33kΩ (R2)
A3 12V Solar Panel Voltage Divider: 100kΩ (R3) / 20kΩ (R4)
D7 5V Relay Module (DC Pump) Digital Output (Active LOW)
D8 Sensor Power Gate (PNP/MOSFET) Anti-corrosion Power Duty Cycle
D13 Status / Fault LED Onboard Diagnostics
Autonomous Decision Logic Reference
  • Pump Trigger Condition:
    (Soil Moisture < 35%) AND (Surface Water < 80%) AND (Battery > 10.0V)
  • Pump Stop Condition:
    (Soil Moisture >= 65%) OR (Surface Water >= 80%) OR (Battery <= 10.0V)
  • Max Runtime Protection:
    Continuous pump run capped at 180 seconds with mandatory cooldown.
  • Solar Charging Profile:
    vSolar > 12.0V = Active Solar Harvest | vSolar < 2.0V = Night Mode
